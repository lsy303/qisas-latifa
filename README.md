# قصص لطيفة

مكتبة قصص مصورة تُقرأ مثل الكتاب.

الرابط: https://lsy303.github.io/qisas-latifa/

## هيكل الملفات

```
qisas-latifa/
├── index.html          الصفحة الرئيسية (لا تحتاج تعديل)
├── stories.js          قائمة القصص — هنا تضيف كل قصة جديدة
├── assets/             اللوقو والأيقونة
└── yawm-ghair-adi/     مجلد قصة «لم يكن يوماً عادياً»
    ├── index.html      الكتاب نفسه
    ├── cover.jpg       صورة الغلاف في الصفحة الرئيسية
    └── share.jpg       الصورة اللي تطلع عند مشاركة الرابط
```

## إضافة قصة جديدة

1. ارفع مجلد القصة الجديدة (فيه `index.html` و `cover.jpg`).
2. افتح `stories.js` واضغط على أيقونة القلم للتعديل.
3. انسخ القصة الموجودة والصقها في أعلى القائمة، وغيّر بياناتها:

```js
  {
    folder: "اسم-المجلد",
    title: "عنوان القصة",
    blurb: "سطر قصير عن القصة",
    cover: "اسم-المجلد/cover.jpg",
    pages: 12,
    isNew: true
  },
```

4. احذف `isNew: true` من القصة السابقة عشان تختفي عنها علامة «جديدة».
5. اضغط **Commit changes**، وبعد دقيقة تظهر القصة في الموقع.

## تغيير صورة الغلاف

ارفع صورة جديدة بنفس الاسم `cover.jpg` داخل مجلد القصة، وتستبدل القديمة تلقائياً.
المقاس الأنسب: عرضي بنسبة 16:10 (مثلاً 1200 × 750).
