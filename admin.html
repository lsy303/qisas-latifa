مفتاح الدخول (مرة واحدة فقط)

اللوحة تحتاج مفتاح من GitHub عشان تقدر تحفظ في الموقع. يتحفظ في هذا المتصفح بس، ولا يشوفه أحد.
  1. افتح صفحة إنشاء مفتاح جديد (وأنت مسجل دخول في GitHub).
  2. Token name: اكتب أي اسم، مثلاً: qisas-admin. Expiration: اختر المدة اللي تبيها (مثلاً سنة).
  3. Repository access: اختر Only select repositories ثم اختر qisas-latifa.
  4. Permissions: افتح Repository permissions وخل Contents على Read and write.
  5. اضغط Generate token، انسخ المفتاح (يبدأ بـ github_pat_) والصقه هنا.
